# Image Resize

is a tool to allow users to scale a folder or directory of images to a preferred width and will auto scale the height.

The purpose of this tool is to batch format images for social media, blog posts, or websites. Although you can do this with traditional editors the point is you can knock out a batch with one go. The same goes for websites. you could scale your images with css or you can just have images the size you need to begin with.

The plan is to make sure that it works on both windows and linux
